# Week 8 Assignment: My Personal Toolkit

## Project Description

My Personal Toolkit is a Python program that contains three useful tools:

1. **Simple Calculator:** Performs addition, subtraction, multiplication, and division.
2. **To-Do List:** Allows users to add, view, and remove tasks.
3. **Number Guessing Game:** Allows users to guess a random number between 1 and 10.

The program uses loops, lists, conditionals, functions, exception handling, and f-strings.

## Project Files

- **toolkit_plan.txt:** Contains the plan and menu design for the toolkit.
- **toolkit.py:** Contains the main program and all three tools.
- **screenshots/:** Contains screenshots showing the menu and each tool working.

## How to Run

1. Install Python on your computer.
2. Open CMD in the project folder.
3. Run the command:

   `python toolkit.py`

4. Select a tool from the menu.

## Reflection

The hardest part was creating the menu loop so that users could return to the main menu after using each tool. The bug that took the longest to fix was handling invalid user input without crashing the program. I learned how to use loops, lists, and conditionals to create an interactive application. I also learned how functions make code easier to organize and understand. Testing each tool helped me identify and correct mistakes. If I had one more week, I would add a feature to save to-do tasks in a file so they remain available after closing the program.
